 Workspace

What a workspace is, how to set one up, what it remembers, and how to fork it.

 What a workspace is

 A private, always-on agent that reads what you give it, remembers it, and answers questions about it later.

 Set up a workspace

 Sign in, pick a plan, wait a few minutes, start talking. Nothing to install.

 Memory

 Everything the workspace remembers, as folders and notes you can open and read.

 Use the memory from other assistants

 The workspace remembers. Claude, ChatGPT and OpenClaw can read that memory, and write to it, without anything running on a laptop.

 Fork a workspace for a group

 Snapshot it into a separate workspace, give a team access to that one, throw it away when you are done. The original never changes.

 Export a workspace

 What an export includes, what it leaves out, and how to take one.

 Skills

The jobs a workspace knows how to run, and the ones that run without being asked.

 Skills and scheduled work

 Jobs the workspace knows how to run. Some you launch, some run overnight without being asked.

 Tools

The accounts a workspace reaches, and pointing ChatGPT, Claude or a terminal at the same ones.

 Tools, from anywhere

 The workspace's tools also work from a terminal and from other AI assistants. Every use is recorded, and nothing runs until you allow it.

 Connect accounts

 Google, GitHub and Telegram. Connect once and the workspace reads from the source instead of waiting for you to paste.

 Connect an assistant

 Point ChatGPT, Claude, or anything that speaks MCP at connected email, calendar, Drive, research tools, and what the workspace remembers.

 Applications

 The accounts and keys a client reaches through. Held on our servers, never handed to an assistant.

 Permissions

 What a client may reach, per application, at a level you set.

 Limits

 Every tool has a daily allowance, so an assistant that goes wrong costs you a day and not a month.

 Activity

 Every call an assistant made, what it did, which connection made it, and what it cost.
