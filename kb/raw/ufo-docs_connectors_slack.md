Connecting Slack

Connect SlackSection titled “Connect Slack”

OAuth
Workspace
Admin only

Ask in chat
Send this message to the agent.
Copy
```
Connect this workspace to Slack.
```

or

Use Connectors
Find Slack on the Connectors page.Open Connectors →

Open the installation link and approve the workspace. Then invite UFO to each channel where it must
work.

Start workSection titled “Start work”

Mention @ufo with a request in a channel. Your UFO replies in a thread. After the first mention,
new messages in that thread continue the same conversation.

Use a direct message for work that must remain private to you. Channel messages and their results
remain visible to the channel audience.

What UFO can doSection titled “What UFO can do”

Complete tasks from a channel or direct message.

Read the thread that started the work.

Post progress, final results, files, and links in the same thread.

Run scheduled work and post it to a selected Slack destination.

You cannot stop work from Slack. Open the conversation in the web portal to stop it.

Fix Slack accessSection titled “Fix Slack access”

If an install link fails, ask for a new one. Install links are short-lived. If your UFO does not
answer, confirm that UFO is in the channel and mention @ufo once.

See Working in Slack.
