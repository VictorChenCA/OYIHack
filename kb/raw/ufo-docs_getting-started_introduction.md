How UFO works

UFO is an AI teammate designed to do real work. It is chat-first, so ask for what you need.

ConversationsSection titled “Conversations”

Use one conversation for each task. Continue in the same conversation when you want to answer a
question, change the result, or add a related task. Start a new conversation for unrelated work.

You can leave a conversation while your UFO works. Return to read its progress and result.

Tools and accessSection titled “Tools and access”

Your UFO can use a browser, a terminal, connected accounts, synced knowledge, and tools for files
and websites. It only uses accounts and sources that are connected and granted to it.

Some actions need your approval. Follow the approval steps in UFO’s reply. Enter secrets in the
private credential form. Never put a password, key, or token in a chat message.

ResultsSection titled “Results”

Your UFO can return an answer, change a connected system, open a pull request, or share a file or
website. Its result states what happened and what it verified.

Ask for a specific check when it matters. For example:

Find the cause of this checkout error. Reproduce it, fix it, and test the customer flow in a
browser. Open a pull request, but do not merge it.

Work that repeatsSection titled “Work that repeats”

Ask your UFO to repeat a task on a schedule. It creates a task that you can inspect, pause, edit,
or delete. Each run has its own conversation. See Scheduled work.

Work across conversationsSection titled “Work across conversations”

Your UFO remembers preferences and decisions across conversations. Some memories are private;
others are shared with the workspace or a channel.
It can also search connected sources. See Knowledge and memory and
Synced sources.
