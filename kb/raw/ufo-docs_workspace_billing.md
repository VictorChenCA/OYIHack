Balance and billing

A workspace runs on a prepaid balance. The cost of each task is deducted from the balance.
You can add unlimited members without a per-member charge.

Only an admin can see billing details, get a billing portal link, or change a refill rule. Use a
private conversation for billing.

Check your balanceSection titled “Check your balance”

Ask your UFO:

Show the workspace balance, reserve, card status, and automatic refill rule.

The reserve is the minimum balance needed to start work on a message. Work can stop even when
the displayed balance is above zero if the remaining amount is below that reserve.

Save or change a cardSection titled “Save or change a card”

Ask for a fresh billing portal link, or use the button on the billing page. Card details, invoices,
and billing information are handled through that short-lived link. UFO does not show a card form.

Saving a card does not add credit. Configure an automatic refill after the card is saved.

Automatic refillsSection titled “Automatic refills”

Set a whole-dollar refill amount and the balance that triggers it. Use the billing page or ask the
agent:

Refill $100 when the balance falls below $25.

You can change or disable the rule. If a card is refused, fix the card and set the refill again.

A one-time credit purchase is not available. A refill rule remains active until an admin disables
it.

When credit runs outSection titled “When credit runs out”

A member message is held. It runs automatically after an admin adds credit, so the member does not
need to send it again.

A scheduled task does not start. The task runs again at its next scheduled time.

Your own model provider keySection titled “Your own model provider key”

A workspace can enter its own model provider key through a private credential form. It pays that
provider directly for model use. Generated media and calls made by your UFO’s working environment
can still spend the UFO balance.
