Set up your workspace

Create the workspaceSection titled “Create the workspace”

Go to https://ufo.ai and select Get started.

Enter your work email.

Enter the code from your email, or select Continue with Google.

Confirm your company website, roles, tools, and current priorities.

Connect Slack, set up billing, or start a tour.

Join an existing workspaceSection titled “Join an existing workspace”

Sign in with your work email. If its domain already has a workspace, you join it directly. You do
not need another invitation or an approval.

An admin can also add you by your exact email address before you sign in. This works for contractors
and advisers who use another email domain.

Add your teamSection titled “Add your team”

Ask your UFO to add a member:

Add marshall@ufo.ai as a member and send the sign-in email.

An admin can add the member from the Team page instead. Turn off Notify
to add a member without sending an email.
Members are not billed by seat. See Members and admins.

Connect the tools for one taskSection titled “Connect the tools for one task”

Choose a first task. Connect only the accounts and knowledge that task needs.

A pull request review needs a GitHub connection. A weekly product report may
need your analytics service, issue tracker, and shared project notes.

Ask your UFO to start each connection:

Connect my GitHub account so you can review pull requests.

Open the connection link in UFO’s reply. See Connecting your systems.

Run the first taskSection titled “Run the first task”

Use one of the recipes or write a request with a clear outcome, useful context, and a
way to check the result.
