# Hackathon Logistics
- Submissions open at 4 PM via a dedicated link (to be shared again at close)
  - Required: GitHub URL, demo video (1-2 min), team name, emails, project description, side quest selection
  - Side quest selection helps judges route projects to the right reviewers
- Judges focus on work built within the hackathon timeframe, not forked/pre-existing projects
- Double-check GitHub and video links are public before submitting
- Build spaces: main room, room next door, and field space downstairs (left out of main room, left down stairs)
