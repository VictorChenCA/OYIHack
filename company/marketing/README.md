# Marketing planet

**Project:** Launch campaign (`launch`)

What the agents produce here:
- `x-thread.md`: the C&C launch thread for X (hook, 6–8 posts, CTA).
- `show-hn.md`: the Show HN title and post.
- `tiktok-30s.md`: a 30-second TikTok/Reels script with shot list and captions.

Posting needs accounts (X, TikTok, HN). Agents stop and name exactly what's missing; those become the planet's **gold** blockers.
